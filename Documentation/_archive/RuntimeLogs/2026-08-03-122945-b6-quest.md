## Problems & solutions
- First assumption was WRONG: `EnterWorld.loadTutorial` only *advances* an existing Tutorial state
  (`getQuestState(...) != null → notifyEvent("UC")`); it does NOT *create* one. DB-made bots that skipped
  client char-creation have no tutorial → `QuestList` was empty (questCount=0).
- Fix: seed the minimal `<state>=Started` row (a legitimate fixture = the state a client has after opting
  into the tutorial at char-creation). On enter-world the server then genuinely ran Q00255's `UC` handler.
- Verified via DB **BEFORE/AFTER delta** (not the QuestList — the Tutorial is excluded from the visible list
  by its `Ex` flag, so QuestList shows 0 *by design*). The DB delta is the primary proof.
