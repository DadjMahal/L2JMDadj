## Protocol notes (for Stream C wiring)
- Client `RequestJoinParty`(0x29): `[0x29][targetName:UTF-16LE null-term][partyDistributionTypeId:int]`
  (invite by NAME; dist RANDOM=1).
- Client `RequestAnswerJoinParty`(0x2A): `[0x2A][response:int]` (1=accept).
- Server `ASK_JOIN_PARTY`(0x39) `[requestorName][distId]` → invitee; `JOIN_PARTY`(0x3A) → requestor.
- Server party windows: `PARTY_SMALL_WINDOW_ALL`(0x4E) → **the new joiner** (full window);
  `PARTY_SMALL_WINDOW_ADD`(0x4F) → **existing members** (leader gets Add). Sent only by `Party.addPartyMember`
  after a real `Party` exists (`new Party(requestor,...)` + `player.joinParty(...)`).
